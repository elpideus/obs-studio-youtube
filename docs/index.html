obs-studio-youtube

OBS Studio for Arch Linux and derivatives, with the YouTube account integration and Game Capture audio.

Source and install guide Google API client setup Privacy policy

What it is

Distribution builds of OBS Studio cannot offer YouTube's Connect Account and Manage Broadcast, because those need a Google OAuth client compiled into the program. This project builds the unmodified OBS Studio source with the same options as Arch Linux's package, plus the YouTube integration, using a Google OAuth client that each user creates for themselves. With it you can sign in to YouTube from OBS, pick one of your scheduled broadcasts, and use the live chat dock.

It also packages a fork of obs-vkcapture whose Game Capture source has a Capture Audio option, like the Windows one: it records the audio of the game it captures, and nothing else.

Packages
  • obs-studio-youtube, obs-studio-youtube-plugin-browser: replace obs-studio, obs-studio-plugin-browser
  • obs-vkcapture-audio, lib32-obs-vkcapture-audio: replace obs-vkcapture, lib32-obs-vkcapture (fork)
  • obs-youtube-update: rebuilds OBS when your repositories update obs-studio

Install

git clone https://github.com/elpideus/obs-studio-youtube.git
cd obs-studio-youtube
./install.sh

The installer asks for your Google OAuth client the first time. See the setup guide.

Your data

Your YouTube sign-in goes straight from your computer to Google. The sign-in token is stored only in your local OBS configuration. Nothing is sent to this project or to anyone else. Details are in the privacy policy.
