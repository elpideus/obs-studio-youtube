Who this covers

This policy covers obs-studio-youtube, an unofficial build of the free software OBS Studio for Arch Linux. It also covers the Google OAuth clients that users of this build create and configure with this page as their privacy policy. The project is maintained by Stefan Cucoranu. It is not affiliated with the OBS Project or Google.

What data is accessed

Only when you choose Connect Account for YouTube in OBS, the program asks Google for permission to use the scope https://www.googleapis.com/auth/youtube on your behalf. OBS uses it to:

  • show your channel name;
  • list, create and update your live broadcasts (title, description, privacy, category, latency, DVR, thumbnail), and bind them to a stream;
  • get the stream key and ingest address for the broadcast you choose;
  • start and end broadcasts, and show the live chat of the current broadcast.

Where it goes and where it is stored

  • All requests go directly from your computer to Google/YouTube. Nothing is sent to the maintainer of this project or to any other third party.
  • The sign-in tokens Google issues are stored only on your computer, in your OBS configuration (~/.config/obs-studio/basic/profiles/<profile>/basic.ini).
  • This build adds no analytics, telemetry or tracking. The OBS program itself is unmodified upstream source.

Sharing and use

Data obtained through Google APIs is used only to provide the features listed above, in OBS on your computer. It is not sold, shared, transferred to others, or used for advertising. Use and transfer of information received from Google APIs adheres to the Google API Services User Data Policy, including the Limited Use requirements.

The YouTube features use the YouTube API Services. By using them you agree to the YouTube Terms of Service, and Google's processing is covered by the Google Privacy Policy.

Removing access and data

  • In OBS: Settings › Stream › Disconnect Account. This deletes the stored tokens from that profile.
  • At any time, revoke the app's access at myaccount.google.com/permissions.
  • Deleting your OBS configuration folder removes everything this build stored.
